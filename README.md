# User Authentication
 
A practice project focused on implementing authentication from scratch with Passport.js, sessions, and bcrypt. The goal is to have a clear reference for how authentication works.

🔗 [Live Demo](https://user-authentication-zqvq.onrender.com)
 
## Features
 
- User registration with hashed passwords (bcrypt)
- Login and logout with persistent sessions (Passport.js + express-session)
- Duplicate username handling
- Protected profile page (auth required)
- Edit username
- Change password
- Delete account
- Public routes redirect logged-in users away from login/register

## Built with
 
- Node.js
- Express
- Passport.js (passport-local)
- express-session
- bcryptjs
- EJS
- PostgreSQL
- Neon
